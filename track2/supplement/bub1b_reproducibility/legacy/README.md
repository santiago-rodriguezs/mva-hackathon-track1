# Earlier structural calculation

These files document the earlier three-site analysis (N1002, T1008, L1012) and its recorded outputs. The final eight-site analysis is in `../analysis/`.

Run `python analyze_structure.py` and `python plot_results.py` from this directory. Source paths were adapted to share the frozen references in `../analysis/inputs/`; numerical methods were not changed. New outputs go to `rebuilt/`. The plotting script uses the archived measurements and the same frozen PDB. The archived JSON includes its original runtime and hashes.

This is WT geometry, not mutant modeling, dynamics or evidence of drug rescue.
