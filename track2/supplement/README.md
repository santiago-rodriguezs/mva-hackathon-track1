# Computational supplement — Track 2

The reproducible support package is available in [bub1b_reproducibility/](bub1b_reproducibility/).

It contains the frozen public FASTA/CDS/PDB inputs, original and extended structural analyses, comparator annotations, phase-aware scenario rules, archived CSV/JSON results, report-generation code, methods answers, the procedural animation with fonts/assets, and verification scripts.

Start with the [README](bub1b_reproducibility/README.md) and [evidence map](bub1b_reproducibility/EVIDENCE_MAP.md). Numerical results and hypotheses are explicitly distinguished.

The existing submitted PDF and methods workbook in the parent Track 2 directory are preserved, including the team addendum and disclosures. No raw proband sequencing or genotype call tables are included.
